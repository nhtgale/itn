Примерный список тем:
- Начать с вступления, сетевой модели, протоколов, примеров взаимодействия.
- Дальше по книге канальный уровень:
  - Кодирование, модуляция
  - Фрейминг, детектирование ошибок
  - Надежная доставка
  - Сети с множественным доступом, кратко про эзернет
  - Беспроводные сети
  - Сети доступа
- Базовое межсетевое взаимодействие
  - Основы коммутации (на основе датаграмм и виртуальных каналов)
  - Коммутация Ethernet. Подробно про ethernet, про стандарты, про автосогласование, mdix и auto mdix, броадкаст и мультикаст
  - Интернет как объединение множества разных сетей
  - IP, формат, свойства
  - Классы сетей, маска сети, подсети
  - Взаимодействие в рамках одной сети, ARP
  - Основы маршрутизации, таблица маршрутизации, маршрут по умолчанию
  - DHCP, ICMP
- Транспортный уровень
  - Порты
  - UDP
  - TCP
- Приложения
  - DNS
  - SSH
  - Telnet
  - HTTP
  - etc
- Базовая работа с сетевыми устройствами и их настройка
  - Подключение консолью
  - Синхронизация логирования, отключение днс-лукапа, пароль на привилегированный режим, пароль на консоль, создание юзеров и т.д

Добавить роутер, настроить компьютеры во второй сети при помощи dhcp. Телнет, SSH, dns.
